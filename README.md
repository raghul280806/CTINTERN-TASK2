TASK 2: ERC-20 TOKEN CREATION AND DEPLOYMENT (500+ WORDS)

Task 2 focused on creating a custom cryptocurrency token using the ERC-20 standard. ERC-20 is the most widely used token standard on the Ethereum blockchain and defines a common set of rules that all fungible tokens must follow. The goal of this task was to understand how digital tokens are created, managed, and transferred on a blockchain network.
The task began by studying the ERC-20 standard, including important functions such as totalSupply, balanceOf, transfer, and events like Transfer. These components ensure compatibility with wallets, exchanges, and decentralized applications. A Solidity smart contract was written to implement these features, defining token name, symbol, decimals, and total supply.
The contract was written in Remix IDE using Solidity version 0.8.x. During development, special attention was given to token supply calculation, balance mapping, and secure transfer logic. The constructor was used to mint the initial supply of tokens and assign them to the deployer’s address. This helped in understanding token minting and ownership concepts.
After writing the code, the contract was compiled and deployed using Remix VM (London). Deployment required passing the initial token supply as an input parameter. Once deployed, the contract address was generated, and token functions became accessible.
Post-deployment, various token functions were tested. The balanceOf function was used to check token balances, and the transfer function was used to send tokens between accounts. Remix provides multiple test accounts, making it easy to simulate real-world transactions. Successful transfers confirmed that the ERC-20 implementation worked correctly.
This task provided deep insight into how cryptocurrencies like stablecoins and utility tokens operate. It also explained how token standards enable interoperability across blockchain platforms. Overall, Task 2 strengthened understanding of decentralized assets and practical blockchain token development
